# FoldGPT public media

- The application icon is a direct vector transcription of FoldGPT Android's foldgpt_icon.xml: same three paths and colors, no substitute logo.
- foldgpt-social.png is a faithful 1280 × 480 raster export of the public repository's docs/assets/foldgpt-banner.svg. It uses the julienpiron.fr brand and the exact application icon. It is vector artwork rendered with CairoSVG, not AI-generated imagery, a photograph, or a device demonstration.
- codex-desktop-anonymized.png is a genuine development-device capture with two limited, direct pixel edits authorized by the owner: the account name is replaced with the illustrative placeholder `you@gmail.com`, and the personal avatar with a neutral user pictogram. The placeholder is not the actual account identity. Every pixel outside those two small account regions matches the original capture, including the complete composer, model selector and access controls. No generative image model was used. It replaces the earlier version with oversized black masks.
- workspace-runtime.png is an unmodified development-device capture of workspace settings.
- android-keyboard.png is an unmodified development-device capture of a Samsung split-keyboard input test.
- These are historical screenshots, not a connected browser session or a video demonstration. The interactive handset is a WebGL visualization using the same account-anonymized capture as its screen texture; it is not a photographic device recording.
- ChatGPT/Codex interface and Samsung keyboard marks belong to their respective owners; shown for interoperability documentation. FoldGPT is independent.
