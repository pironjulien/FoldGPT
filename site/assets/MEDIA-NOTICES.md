# FoldGPT public media

- The application icon is a direct vector transcription of FoldGPT Android's foldgpt_icon.xml: same three paths and colors, no substitute logo.
- codex-desktop.png is a genuine development-device capture. Account, avatar and active session controls are covered by opaque pixel masks. No other pixels were reconstructed or generated.
- workspace-runtime.png is an unmodified development-device capture of workspace settings.
- android-keyboard.png is an unmodified development-device capture of a Samsung split-keyboard input test.
- These are historical screenshots, not a connected browser session or a video demonstration. The interactive handset is a WebGL visualization using a real redacted capture as its screen texture; it is not a photographic device recording.
- ChatGPT/Codex interface and Samsung keyboard marks belong to their respective owners; shown for interoperability documentation. FoldGPT is independent.
