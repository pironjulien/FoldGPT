# Publication scope

This public repository is a source release of the FoldGPT Android host and its runtime integration. It is intentionally separate from private recovery material.

Verified on the development phone: the repaired native executor is admitted, the workspace is available, and a Python command executed through a real Codex discussion returned `4`. Android security observations at that time were verified boot `green`, locked bootloader, and Knox warranty bit `0`.

Open qualification gates are fresh installation, updates, Remote, prolonged background/fold cycles, multiple simultaneous discussions, and broader isolation/tool coverage. The Android phantom-process budget remains a platform constraint. Ordinary sub-applications cannot create an independent quota: Android still accounts for child processes under the application UID and system policy.

Do not publish APKs, extracted client files, account data, browser profiles, private logs, device serials, or encrypted recovery archives from this repository.
