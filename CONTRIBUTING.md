# Contributing to FoldGPT

Open an issue for a reproducible bug or a focused proposal. Pull requests should explain the user-visible change, list the checks run, and identify any device-specific evidence.

Do not include credentials, OAuth material, browser profiles, APKs, Linux images, device serials, private logs, or files copied from a ChatGPT account. Do not claim Android, Knox, Samsung Pay, Remote, update, or multi-conversation compatibility without a reproducible test.

A maintainer reviews and merges pull requests. Contributors can suggest improvements without write access to the default branch.
